# Future Me at 60

An English-language personal portfolio by Polat Yerdaulet. The site presents current studies and independent projects alongside a clearly labelled fictional career at age 60.

## Open the website

Extract the entire ZIP and open `index.html` in a web browser. Keep the folder structure intact so the stylesheet, JavaScript, favicon, and images load. The site uses HTML5, an external CSS3 stylesheet, and vanilla JavaScript. It has no build step or package dependencies. Google Fonts can load online. System fonts are available offline.

## Source guide

- `index.html` contains the English copy, career table, plan for the imagined future, project disclosures, and demo contact form.
- `style.css` contains the color themes, Grid and Flexbox layouts, and responsive breakpoints. The Interests section demonstrates float and clear.
- `script.js` handles the mobile menu, theme persistence, navigation highlighting, scroll progress, and local contact validation.
- `images/` contains the illustrated profile placeholder and project art. The browser selects a smaller profile asset on mobile. The local `favicon.ico` contains the PE tab icon.
- `report/Lab11_Report.pdf` contains the laboratory report and defence study notes.

The contact form validates sample input in the browser. It uses no email service or server. The site stores the chosen theme in localStorage. Project links and social profiles can be added when their verified URLs are available.
